# EditFlow - Video Editing Agency Website

A modern, responsive website for a professional video editing agency built with React and Tailwind CSS.

## Features

- 🎨 Modern UI with Tailwind CSS
- 📱 Fully responsive design
- 🎬 Portfolio showcase
- 📞 Contact form
- 🔐 Admin dashboard
- 📹 Video upload functionality
- 💬 WhatsApp integration
- 🚀 Fast performance with Vite

## Tech Stack

- React 18
- Tailwind CSS
- React Router DOM
- Vite
- Swiper.js
- React Icons
